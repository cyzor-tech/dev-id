# DEV ID - Plataforma Completa - Developer Workspace

## 10 Páginas Implementadas - Design System Fiel à Referência
Fundo #F8F5F1, cards branco 28px radius, sombra soft, pills pretas #111

### Páginas:
1. Dashboard / Overview - Visão geral, métricas, Technical DNA, Portfolio
2. Identity - Foto, headline, cargo, senioridade, location, idiomas, links, privacy, public preview
3. Career - Timeline interativa 2019-2024, experiências expansíveis, education, certs
4. Skills & Technical DNA - Radar SVG, barras 6y 95%, Evidence Engine, gaps
5. Portfolio - Grid 6 projetos estilo Mystery Residences, galeria, resultados
6. CV Studio - Editor A4 drag&drop, templates, ATS Score, generate PDF
7. Integrações - GitHub 342 contributions, LinkedIn, GitLab, sync timeline
8. Oportunidades - Matching 94%, vagas cards, pipeline Kanban, invites
9. Analytics - Views 1.24k, line chart 30d, origem donut, engagement
10. Personalização - Themes, public profile layout, domínio custom, preview ao vivo

### Como usar:
Abra dev-id-completo/index.html no navegador - app SPA navegável com 10 páginas
Sidebar flutuante troca páginas sem reload

### Stack:
React + Tailwind, SVG custom, sem libs externas, dados mock realistas
