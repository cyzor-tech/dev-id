# DEV ID - Dashboard Principal
Dashboard premium baseado na referência visual fornecida.

## Como usar
1. Abra dist/index.html no navegador - é o build completo e funcional
2. Ou use o código em src/ em um projeto Vite + React + Tailwind

## O que está incluso
- dist/index.html -> Dashboard final (mesmo que preview)
- standalone/ -> versão alternativa
- src/App.tsx + index.css -> código fonte React
- referencia-visual.jpg -> referência original

## Design System
Fundo #F8F5F1, cards branco 28px radius, sombra soft, sidebar flutuante, pills pretas.
Pilares: Identity / Evidence / Opportunity

Pronto para evoluir para Talent Workspace, Perfil Público e Admin.
